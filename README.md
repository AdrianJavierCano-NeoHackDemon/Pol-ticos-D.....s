## Correr el programa localmente

**Prerequisitos:**  Node.js


1. Instala las dependencias:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Corre la app:
   `npm run dev`
